# Plugin review

## Client checks

- Use an existing demo workspace with data reviewers can access.
- [Install the release](../README.md#installation), check the skills and MCP connection, and complete native OAuth.
- Query logs and metrics. Run the starter prompts; configure script credentials where needed.
- Record results locally.

## Submission

- Use [manifest text](../.codex-plugin/plugin.json), [the icon](../assets/axiom.png), and release notes. Set the support URL to <https://axiom.co/support>.
- For [OpenAI](https://developers.openai.com/plugins/deploy/submission), provide five positive cases, three negative cases, expected tools/results, and a demo recording.
- Enter reviewer credentials in the secure portal. Complete required tool annotations, domain verification, and scans.
- Follow the [provider submission steps](marketplaces.md#publish-and-update).
