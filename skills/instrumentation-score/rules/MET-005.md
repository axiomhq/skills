**Rule ID:** MET-005

**Description:** Metric names do not contain the name of the metric unit.

**Rationale:** The metric unit is already provided as part of the unit of the metric per the metric model. The metric name duplicates the metric unit and can be less descriptive. It also implies breaking changes if the unit changes at a later time.

**Target:** Metric

**Criteria:** Metric names MUST NOT contain the metric unit (example: `collection.duration.seconds`).

**Impact:** Normal

**Example Query:**

```http
GET /v1/query/metrics/info/datasets/otel-demo.metrics/metrics?start=2026-11-04T23:45:00Z&end=2026-11-18T23:45:00Z
Accept: application/vnd.metrics-info.v2+json
```

Compare meaningful name components with unit names and abbreviations, such as
`seconds` for `s` and `bytes` for `By`. Count annotations such as `{request}`
describe the entity; a substring match alone does not establish a violation.
