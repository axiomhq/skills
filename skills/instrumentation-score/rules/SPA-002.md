**Rule ID:** SPA-002

**Description:** Traces do not contain orphan spans.

**Rationale:** Orphaned spans indicate potential issues in tracing instrumentation or data integrity. This can lead to incomplete or misleading trace data, hindering effective troubleshooting and performance analysis.

**Target:** Span

**Criteria:** Given any span with a `parent_span_id` reference, here MUST exist a span with the same trace id whose `span_id` equals that `parent_span_id` value.

**Impact:** Normal

**Example Query:**

```apl
// Keep the whole trace together so parents from other services remain visible.
// Recheck these missing-parent candidates outside the query window.
['otel-demo-traces']
| summarize
    span_ids=make_set(span_id, 1000),
    parent_ids=make_set_if(parent_span_id, isnotempty(parent_span_id), 1000)
  by trace_id
| extend missing_parent_ids=set_difference(parent_ids, set_intersect(parent_ids, span_ids))
| where array_length(missing_parent_ids) > 0
| project trace_id, missing_parent_ids
| take 10000
```
