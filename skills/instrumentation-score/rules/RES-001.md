**Rule ID:** RES-001

**Description:** `service.instance.id` is present.

**Rationale:** The `service.instance.id` uniquely identifies a resource, and can be used as the process identifier without taking other resource attributes into account.

**Target:** Resource

**Criteria:** The `service.instance.id` resource attribute MUST appear in the resource.

**Impact:** Normal

**Example Query:**

```apl
// Axiom stores this resource attribute in the top-level service.instance.id field.
['otel-demo-traces']
| summarize
    observed=count(),
    missing_instance_id=countif(isnull(['service.instance.id']))
  by ['service.name']
```
